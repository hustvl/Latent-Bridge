## Introduction

Official repository for **Latent Bridge: From Video Latents to 3D Geometry via Feature Alignment**.

Latent Bridge connects video generative latents to frozen geometric features through feature alignment. Visit our [project page](https://shuaizhang7.github.io/latent-bridge-page/) for the method overview, video comparisons, and interactive 3D visualizations.
